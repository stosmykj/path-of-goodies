## Technical Specifications by Platform

### For Midjourney
- Add: `--style raw` for pixel art to avoid over-stylization
- Add: `--v 6` for latest version
- Add: `--ar 16:9` or `--ar 1:1` depending on needs
- Add: `--no blur, no gradient` for sharp pixel art
- Example: `[pixel art prompt] --style raw --v 6 --no blur --ar 16:9`

### For DALL-E 3
- Include "game asset" or "game UI" for functional design
- Specify "transparent background" if needed
- Be very explicit about pixel dimensions
- Can handle complex scene descriptions well

### For Stable Diffusion
- Model recommendations:
  - Pixel art: "Pixelart-XL" or "Pixel Art Diffusion"
  - Hand-drawn: "Dreamshaper" or "Anything V5"
- Use LoRAs for style consistency
- Negative prompts for pixel art: `blur, gradient, anti-aliasing, smooth, realistic`
- Negative prompts for hand-drawn: `photograph, 3d render, blurry`

### For Leonardo.ai
- Use "Pixel Art" preset for pixel style
- Use "Anime" or "Fantasy Art" preset for hand-drawn
- Adjust "Prompt Magic" strength
- Enable "Alchemy" for better quality

## Usage Tips

1. **Start Simple**: Test basic prompts first, then add details
2. **Iterate**: Generate multiple versions and refine
3. **Be Specific**: More detail = better results
4. **Reference Games**: Mentioning similar games helps AI understand style
5. **Consistency**: Use same prompts structure for related assets
6. **Post-Process**: Touch up in pixel editor (Aseprite) or painting software (Krita)
