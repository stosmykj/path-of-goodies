# Complete Asset List

## Overview

This document catalogs every asset needed for Path of Goodies, organized by type and priority. Use this as a checklist for asset creation.

## Priority Levels

- **P0 (Critical)**: Needed for MVP, blocks all gameplay
- **P1 (High)**: Needed for core features
- **P2 (Medium)**: Enhances experience, not essential
- **P3 (Low)**: Polish and variety

## Asset Creation Order

### Phase 1: MVP (P0 Assets)
1. Player wagon + horse (idle only)
2. Village icons (4 sizes)
3. Basic UI icons (gold, food, water, health, stamina)
4. UI panels and buttons
5. Basic terrain (grass, path)
6. Core data files

**Goal**: Playable prototype with basic gameplay

### Phase 2: Core Features (P1 Assets)
1. Guard sprites (all 4 types)
2. Horse animations (walk, tired)
3. Enemy encounter sprites
4. Terrain backgrounds
5. UI sounds
6. Gameplay sounds

**Goal**: Complete gameplay loop with all core features

### Phase 3: Content (P2 Assets)
1. NPC encounter sprites
2. Equipment icons
3. Props and decorations
4. Music tracks
5. More sound effects

**Goal**: Rich, varied experience

### Phase 4: Polish (P3 Assets)
1. Visual effects and particles
2. Ambient sounds
3. Additional animations
4. Extra variety sprites

**Goal**: Professional polish
