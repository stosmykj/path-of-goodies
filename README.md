# Path of Goodies

A 2D pixel art medieval trading adventure game built with Rust and Bevy.

## Project Status

🚧 **PLANNING PHASE** - This repository is currently in the planning and design phase. No code has been written yet.

## Vision

Path of Goodies is a strategic trading and adventure game set in a medieval fantasy world. Players manage a wagon caravan, traveling between villages to complete delivery contracts, hire guards, manage resources, and face random encounters on dangerous roads.

## Core Gameplay Loop

1. **Accept Contract** - Take delivery jobs in towns
2. **Travel** - Navigate the world map between settlements
3. **Manage Resources** - Food, water, gold, and horse stamina
4. **Handle Encounters** - Bandits, merchants, weather events
5. **Upgrade Party** - Hire guards, buy equipment, rest at inns
6. **Complete Delivery** - Earn rewards and reputation

## Key Features

- **Strategic World Map** - Graph-based travel system with fog of war
- **Resource Management** - Survival mechanics with meaningful choices
- **Party System** - Hire and equip guards to protect your caravan
- **Random Encounters** - Dynamic events that affect your journey
- **Horse Mechanics** - Living horse with health, stamina, morale
- **Town Services** - Blacksmith, inn, temple, and market interactions
- **Pixel Art Style** - Retro aesthetic with modern design principles

## Technology Stack

- **Engine**: Bevy 0.15 (Rust ECS game engine)
- **Language**: Rust 2021
- **Graphics**: 2D pixel art sprites
- **Deployment**: Native (Windows/Mac/Linux) + Web (WASM)
- **Data Format**: RON (Rusty Object Notation) for modding support
